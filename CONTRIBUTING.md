# Contributing to AYO

Thank you for your interest in contributing to AYO!

AYO (Archive of Your Own) is currently a work in progress. The project is not live yet and does not currently have a production hosting service or deployed database.

Contributions, suggestions, bug reports, and improvements are welcome.

## How to Contribute

### 1. Fork the Repository

- Visit the AYO GitHub repository.
- Click **Fork** in the upper-right corner.
- This creates your own copy of the project under your GitHub account.

### 2. Clone Your Fork

Download your fork to your local computer:

```bash
git clone https://github.com/YOUR-USERNAME/Archive_of_your_own.git
cd Archive_of_your_own
```

Replace `YOUR-USERNAME` with your GitHub username.

### 3. Create a Branch

Create a separate branch for your changes:

```bash
git checkout -b feature/your-feature-name
```

For bug fixes, you can use:

```bash
git checkout -b fix/description-of-fix
```

### 4. Make Your Changes

Make your changes locally and test them before submitting.

Please keep contributions focused and avoid introducing unnecessary dependencies or major architectural changes without discussion.

### 5. Commit and Push

Save your changes and push your branch to your fork:

```bash
git add .
git commit -m "Describe your changes"
git push origin feature/your-feature-name
```

### 6. Open a Pull Request

- Visit your fork on GitHub.
- Click **Contribute** and select **Open pull request**.
- Make sure the base repository is the original AYO repository and the base branch is `main`.
- Describe what you changed and why.
- Submit your pull request for review.

Pull requests will be reviewed before any changes are merged into the main project.

## Guidelines

- Keep code clean, readable, and organized.
- Test your changes before submitting.
- Avoid committing passwords, API keys, or other sensitive information.
